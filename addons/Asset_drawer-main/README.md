# Asset Drawer

Tiroir d'assets pour Godot 4.7, dans l'esprit du Content Drawer d'Unreal : un dock avec vignettes, recherche, filtres, favoris et couleurs de dossier.

## Installation

Mettre le dossier dans `res://addons/Asset_drawer-main/` (le nom compte, les chemins sont écrits en dur), puis activer le plugin dans les paramètres du projet.

## Utilisation

`Ctrl + Espace` ouvre et ferme le tiroir. L'engrenage donne accès à la langue (FR/EN) et à la liste des raccourcis.
